# 🎮 Modern Tic-Tac-Toe

A modern, responsive, and interactive Tic-Tac-Toe game built with pure HTML5, CSS3, and JavaScript.

![Game Preview](https://img.shields.io/badge/Tic--Tac--Toe-Modern_Edition-blue?style=for-the-badge)
![Zero Dependencies](https://img.shields.io/badge/Dependencies-Zero-brightgreen?style=for-the-badge)

## ✨ Features

- 👥 **2-Player Mode**: Play locally with a friend (Pass and Play).
- 🤖 **AI Opponent**:
  - **Easy Mode**: Casual, random moves.
  - **Unbeatable Mode**: Powered by the **Minimax algorithm** — it never loses!
- 🎨 **Modern Dark UI**: Glassmorphism, smooth animations, and neon glow effects for X and O.
- 🔊 **Synthesized Sound Effects**: Built-in sound effects via Web Audio API (with mute toggle, no external audio files required).
- 🎊 **Confetti Celebration**: Smooth custom canvas confetti animation upon winning.
- 📊 **Score Tracker**: Keeps tally of Player X wins, Ties, and Player O/AI wins.
- 📱 **Fully Responsive**: Adapts seamlessly to desktops, tablets, and mobile phones.

## 🚀 Getting Started

No installation or build steps needed!

1. Clone or download the repository:
   ```bash
   git clone https://github.com/Itzemonxyz/bebsa-pari-na.git
   ```
2. Open `index.html` in any modern web browser.
3. Enjoy the game!

## 🛠️ Tech Stack

- **HTML5**: Semantic markup and accessibility attributes.
- **CSS3**: Modern Flexbox/Grid, CSS variables, glassmorphism, animations.
- **JavaScript (ES6+)**: Game state management, Minimax algorithm, Web Audio API, HTML5 Canvas.
